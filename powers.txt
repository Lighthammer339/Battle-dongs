###############################################################################
#  BATTLE DONGS - POWER LIST
#
#  Every [Section] below is one power. The name in the brackets is what players
#  see. Edit numbers, rename things, delete things, copy-paste to make new ones.
#  The server re-reads this file at the start of every game - no restart needed.
#  Lines starting with # are comments.
#
#  ---------------------------------------------------------------------------
#  KEYS (all optional except type - anything missing uses the default)
#  ---------------------------------------------------------------------------
#  type         what it does - see TYPES below                   (default shot)
#  damage       points scored on a direct hit                    (default 30)
#  radius       explosion size in pixels (field is 640 wide)     (default 16)
#  count        how many: shots, splits, fragments, bounces, hops, bombs...
#  spread       degrees between shots / fan width for splits and fragments
#  delay        seconds between shots for "stream"               (default 0.15)
#  jitter       random wobble in angle/power for "stream"        (default 0)
#  reach        pixels: roll distance, dig depth, fire flow, seek range,
#               air strike half-width                            (default 100)
#  speed        launch speed multiplier, 1 = normal              (default 1)
#  gravity      gravity multiplier, 0 = flies dead straight      (default 1)
#  frag_damage  damage of each fragment / bomblet / bounce pop   (default 10)
#  frag_radius  explosion size of each fragment                  (default 8)
#  frag_speed   how hard fragments get thrown / hop height       (default 150)
#  carve        yes/no - does the explosion dig into the ground  (default yes)
#  shape        dirt only: ball or wall                          (default ball)
#  direction    shove only: push (blast them away) or pull (suck them in)
#  height       dirt walls only: wall height in pixels           (default 40)
#  weight       how often it shows up in the draft, 0 = disabled (default 1)
#  color        projectile + explosion color, like #ffd84a
#  look         glob, ball, nuts, drop, pearl, rocket, dirt, probe (default glob)
#               (nuts = a big pair of balls)
#  size         projectile size in pixels, 1-16                  (default 3)
#  description  the text players see
#
#  ---------------------------------------------------------------------------
#  TYPES
#  ---------------------------------------------------------------------------
#  shot        one projectile, explodes on impact
#  spread      "count" projectiles fanned out "spread" degrees apart
#  stream      "count" projectiles fired one after another, "delay" apart
#  split       one projectile that splits into "count" at the top of its arc
#  cluster     explodes, then throws "count" fragments upward ("spread" = cone)
#  roller      lands, then rolls downhill up to "reach" px or until it hits
#              a wall or a tank, then explodes
#  bouncer     bounces "count" times (a small frag pop each bounce), then explodes
#  jackhammer  explodes, hops back up, explodes again - "count" hops
#  teabag      like the Worms donkey: lands, slams, then floats slowly
#              straight back up over the SAME spot and slams down again -
#              "count" slams total, "frag_speed" = hop height
#  digger      burrows "reach" px into the ground (radius = tunnel width);
#              if damage > 0 it explodes at the end using frag_radius
#  dirt        adds dirt instead of removing it: a ball, or a wall
#  napalm      liquid fire that flows downhill up to "reach" px each way;
#              tanks take "damage" per flame within "radius"
#  seeker      steers toward the nearest enemy within "reach" px
#  airstrike   marks the spot, then "count" bombs fall from the sky across
#              "reach" px either side
#  teleport    moves YOUR tank to wherever it lands. No damage.
#  shove       explodes and shoves every dong within "reach" px sideways, up to
#              "frag_speed" px (less the further away). direction = push / pull
#
#  HEALTH: everyone has 150. Run out and your dong dies - last one standing wins.
#  Crates parachute in during the game: walk over one or shoot it to grab it.
#
#  SCORING: you get points for every point of damage you deal.
#  Hitting yourself SUBTRACTS the damage from your own score.
###############################################################################
